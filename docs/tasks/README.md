# Task Management System

This project uses a file-based task management system located in `docs/tasks/`.

## Workflow
1.  **Create a Task**: Copy the template from `docs/tasks/GUIDE.md` to a new file in the appropriate subdirectory (e.g., `docs/tasks/features/`).
2.  **Status Tracking**: Update the `Status` field in the task file (`Pending` -> `In Progress` -> `Completed`).
3.  **Documentation**: Keep the task file updated with progress, decisions, and outcomes.

## Directories
*   `features/`: New user-facing features.
*   `infrastructure/`: DevOps, CI/CD, database setup.
*   `migration/`: Code refactoring and migrations.
*   `domain/`: Business logic changes.
*   `presentation/`: UI/UX changes.
*   `testing/`: Test coverage and infrastructure.
