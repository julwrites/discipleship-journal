# PWA Setup

### Description
Configure the application as a Progressive Web App (PWA) to enable installation on devices, offline capabilities, and a native-like experience.

### Acceptance Criteria
- [x] **Manifest**:
    - [x] `manifest.webmanifest` (or generated by Vite) includes name, short_name, icons, theme_color.
    - [x] Icons exist in `public/` (192x192, 512x512).
- [x] **Service Worker**:
    - [x] Service worker is registered and caches assets for offline use.
    - [x] App is installable.
- [x] **Meta Tags**:
    - [x] `theme-color` meta tag in `index.html`.
    - [x] `viewport` meta tag configured correctly.
