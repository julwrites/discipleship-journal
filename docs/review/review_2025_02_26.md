## 3. Code Quality & Issues
### Frontend Service Layer Violation
**Issue:** `web/src/pages/GroupsPage.tsx` directly performs `fetch` calls to the API.
**Architectural Guideline:** "API interactions should be encapsulated in `src/services/`."
**Impact:** Harder to test components in isolation, harder to maintain API logic (e.g., error handling, types) if scattered across components.
**Recommendation:** Refactor API calls into `web/src/services/group.service.ts`.

### Backend
*   **Error Handling:** Good use of structured logging and generic HTTP 500 errors for security.
*   **Validation:** Uses `go-playground/validator` correctly.
*   **Missing Unit Tests:** The `api/handlers/` package lacks unit tests (no `_test.go` files found). This is a gap in the "Engineering Excellence" phase.
